## 2026-07-25 - [Binary Pre-allocated Array Lookup Optimization]
**Learning:** For transforming strings to character-by-character 8-bit binary strings, string concatenation in a loop has O(N^2) complexity and nested loops add significant overhead. Pre-allocating the array using `new Array(len)`, using a global lookup table initialized once for all 256 byte values, and using `.join(' ')` leads to over 3x performance speedup. Replicating the truncation behavior of the original unoptimized nested loop via `& 0xFF` is critical to ensuring absolute mathematical equivalence with non-ASCII and surrogate-pair characters.
**Action:** Always pre-allocate the target array using `new Array(len)` and perform character-to-binary or text-to-binary conversions using an initialized-once global lookup table and `.join(' ')` rather than manual nested bit-shifting and repetitive string concatenation.
