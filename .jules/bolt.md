## 2026-07-17 - Performance Lookup Table and DOM Optimization for Binary Conversion
**Learning:** Using nested bitwise loops and string concatenation in a hot loop (O(n^2) behavior due to string copying) is extremely slow for large text-to-binary conversions. Pre-calculating a global 0-255 binary lookup table and using pre-allocated arrays with `Array.join(' ')` provides a dramatic performance improvement (~70x speedup). Additionally, replacing `innerHTML` with `textContent` for simple text DOM updates avoids unnecessary HTML parsing overhead and increases security.
**Action:** When handling bulk character transformations or processing large loops, always pre-calculate lookups where applicable, avoid string concatenation inside loops, and prefer `textContent` over `innerHTML` for displaying plain text.
