## 2026-08-08 - String-to-Binary Bulk Conversion Optimization
**Learning:** In hot loops converting characters to binary representation, calculating 8-bit strings repeatedly using bitwise operations and constructing the result via string concatenation results in O(n^2) time complexity. Using a pre-allocated array of size `input.length` with `Array.join(' ')` paired with an O(1) global lookup table of pre-calculated binary string results for characters 0-255 provides an extremely fast, O(n) optimized alternative that avoids garbage collection overhead. In addition, replacing `innerHTML` with `textContent` for plain-text UI updates avoids expensive HTML parsing and reflows.
**Action:** Always pre-allocate fixed-size arrays when performing character-by-character string transformations in pure JavaScript, utilize static lookup tables for bounded-range inputs, and prefer `textContent` over `innerHTML` when rendering raw string outputs.
