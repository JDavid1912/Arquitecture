## 2026-08-06 - Initial Optimization Findings on String to Binary Conversion
**Learning:** For character-to-binary conversion, string concatenation inside nested loops has O(N^2) complexity. Utilizing a pre-allocated array of size `N` along with `Array.join(' ')` drastically reduces execution times for large inputs. Furthermore, using a pre-computed global lookup table for the 256 standard byte values shifts individual character conversion from O(8) bit-shifting iterations to a single O(1) array access. To maintain absolute equivalence, truncating high-order bits of surrogate pairs using bitwise AND (`& 0xFF`) is required to perfectly mirror the original bitwise logic.
**Action:** Always pre-allocate arrays where the final length is known, build lookup tables for character-to-binary mapping, use bitwise masking for exact legacy truncation replication, and replace `innerHTML` with `textContent` for secure and fast DOM manipulation.
